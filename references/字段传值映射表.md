# 字段传值映射表（AI Agent 节点写入参数）

写入参数统一形态：`{"id":"<alias或字段ID>","value":<按类型>}`，附件额外带 `"type":"1"`。
字段名只用真实 alias 或字段 ID；记录 ID 固定 `rowid`。

## 一、可写字段类型映射

标注说明：✅ = 实测验证；⚠️ = 常见默认写法，首次在目标环境使用时用一个最小用例实测确认（阶段 5 覆盖）。

| 字段类型 | 传值形态 | 示例 | 状态 |
|---|---|---|---|
| 文本 / 多行文本 / 邮箱 / 手机 | 字符串 | `{"id":"title","value":"漏洞告警"}` | ✅ |
| 单选 | 选项文本字符串（不要数组） | `{"id":"level","value":"重大"}` | ✅ |
| 多选 | 选项文本数组 | `{"id":"tags","value":["漏洞","攻击"]}` | ⚠️ 部分环境要求逗号分隔字符串 `"漏洞,攻击"` |
| 日期时间 | `yyyy-MM-dd HH:mm:ss`，只有日期补 `00:00:00` | `{"id":"found_at","value":"2026-11-14 17:57:00"}` | ✅ |
| 仅日期 | `yyyy-MM-dd` | `{"id":"due_date","value":"2026-11-20"}` | ⚠️ 报错则补 `00:00:00` |
| 数值 / 金额 | 数字字符串 | `{"id":"amount","value":"1500.50"}` | ⚠️ 部分环境接受数字 |
| 勾选 | `"1"` 选中 / `"0"` 未选 | `{"id":"is_urgent","value":"1"}` | ⚠️ 部分环境接受布尔 |
| 人员 | 账号 ID 数组 | `{"id":"owner","value":["<accountId>"]}` | ⚠️ AI 无法凭空生成账号 ID：从查询结果取，或平台配默认值 |
| 部门 | 部门 ID 数组 | `{"id":"dept","value":["<departmentId>"]}` | ⚠️ 同人员，ID 必须来自真实数据 |
| 关联记录 | 记录 ID（rowid）数组 | `{"id":"rel_app","value":["176e609d-..."]}` | ✅ |
| 附件 | `{"name","url"}` 对象数组 + `"type":"1"` | 见下方完整样例 | ✅ |
| 子表 | 行对象数组，每行是若干 `{id,value}` | `{"id":"sub_items","value":[[{"id":"item_name","value":"主机A"}]]}` | ⚠️ 结构随环境差异较大，务必实测；能不写子表就拆成主表+关联 |

附件成功样例（实测）：

```json
{
  "id": "attachment",
  "type": "1",
  "value": [
    {"name": "漏洞清单.xlsx", "url": "https://files.example.com/20261114/xxxx.xlsx"}
  ]
}
```

附件三条死规则：键名只能是 `name` / `url`（fileName、downloadUrl 必失败）；value 必须是数组（单文件也是）；`"type":"1"` 不能省。URL 在提示词里用纯文本，不加反引号、不换行。

## 二、只读黑名单（禁止写入，也禁止出现在查询字段里）

| 类型 | 原因 |
|---|---|
| 公式、汇总 | 系统计算，不可写 |
| 自动编号 | 系统生成；查询工具也不支持 |
| 文本拼接 | 同上，查询会报「不存在的控件」 |
| 他表字段（关联 lookup） | 值来自关联表，改源表记录 |
| 系统字段（创建人/创建时间/修改人等） | 平台维护 |

## 三、查询筛选规则

- `contains` / `in` / `concurrent` / `belongsto` 的 `value` 必须是**非空数组**；空数组或字符串直接报结构错误。
- 多个关键字合并进一个数组，不要为每个关键字建一个条件。
- 多个入口字段用 OR 分组；等值匹配用 `eq`，判空用 `isnull` / `isnotnull`（无需 value 或按工具 schema）。
- 查询字段列表避开第二节黑名单；无别名字段用字段 ID。

筛选示例（多字段 OR + 数组值）：

```json
{
  "logic": "OR",
  "children": [
    {"type":"condition","field":"app_url","operator":"contains","value":["a.example.gov.cn","b.example.gov.cn"]},
    {"type":"condition","field":"6aed883b3b368f573ada00f3","operator":"contains","value":["a.example.gov.cn","b.example.gov.cn"]}
  ]
}
```

- 大表必须带筛选，否则受返回条数限制会误判「未匹配」。
- 取记录 ID 时查询字段里带上 `rowid`。
